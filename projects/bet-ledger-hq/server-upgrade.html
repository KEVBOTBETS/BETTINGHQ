Enable ledger history and undo

This is a one-time update to the existing Google Apps Script connected to your ledger. Your sheet, bets, starting bankroll, token, and deployment URL stay in place.

  1. Open your existing ledger spreadsheet. Choose Extensions → Apps Script.
  2. Copy the complete server code below and replace the contents of Code.gs. Save the project.
  3. Choose Deploy → Manage deployments. Select your existing web app and click the edit pencil.
  4. Under Version, choose New version, then Deploy. Keep its current access settings and deployment URL.
  5. Return to Ledger HQ and click Sync. “Ledger audit history” replaces “Observed ledger changes” once the updated server responds.

For an existing connection, you do not need to run setup or resetToken. The server creates its audit tabs automatically. Creating an entirely new deployment would give you a different URL, so update the existing deployment.

What gets recorded

Wager, settlement, deletion, bankroll, and closing-quote changes sent through the upgraded server. Each entry stores the previous and new values with its device and server time. Undo previews those values, then refuses the operation if another edit has changed that record.

Recording starts when this update is deployed. Earlier changes and edits made directly in spreadsheet cells cannot be reconstructed. Ticket backups use the existing connection and work before this upgrade too.
